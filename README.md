The Loki 97 Standard (L97S)

Give the individual the computer back.

L97S is RIDG's engineering standard for technology designed to expand human capability while respecting ownership, privacy, interoperability, local capability, user authority, and honest business models.

Simple for everyone. Powerful for anyone.

Core rule

Technology exists to expand human capability. The system serves the human.

Status

L97S is currently Draft v0.1. The draft is intended for RIDG/internal and early-adopter use while the standard is tested against real products and refined toward a stable v1.0 baseline.
